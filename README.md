# Elise Javetski

Website for Elise Javetski, prenatal and postpartum strength coach in Jersey City.

Edit `_src/site.html` (every page lives in that one file), then run:

    python3 _tools/build.py

That writes the four public pages (`index.html`, `coaching/`, `training-tips/`, `get-started/`) and `sitemap.xml`, each page with its own title, description and search data. Don't edit the built pages directly. Photos live in `img/`; `assets/` holds the source files.
